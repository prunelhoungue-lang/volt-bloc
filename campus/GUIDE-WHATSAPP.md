# Campus Services — lancer d'abord sur WhatsApp

Objectif : avoir de vrais utilisateurs **avant** d'investir dans une application.
La page `campus/index.html` sert d'outil d'appoint : elle met en forme les annonces
pour qu'on puisse les coller proprement dans le groupe.

## 1. Mise en place (semaine 1)

- Créer une **Communauté WhatsApp** « Campus Services — [Nom de l'université] » avec :
  - 📢 **Annonces** (seuls les admins écrivent : règles, nouveautés, top annonces de la semaine)
  - 📚 Résumés & fiches
  - 💼 Petits jobs
  - 🧑‍🏫 Répétiteurs
  - 🖨️ Impression & photocopie
  - 🧮 Calculatrices & fournitures
  - 📌 Petites annonces
- Description du groupe = les règles ci-dessous + lien vers la page d'annonces.
- Recruter 2 ou 3 co-admins (un par faculté si possible).

## 2. Règles à épingler

```
📌 RÈGLES CAMPUS SERVICES
1. Une annonce = un produit ou un service, avec le prix.
2. Format obligatoire (voir modèle). Les annonces hors format sont supprimées.
3. Pas de spam : la même annonce au maximum 1 fois tous les 3 jours.
4. Interdit : sujets d'examen, devoirs faits à la place d'un autre, arnaques.
5. Rencontrez-vous dans un lieu public du campus. Vérifiez avant de payer.
6. Annonce terminée → écrivez « VENDU » en réponse.
```

## 3. Modèle d'annonce

```
📚 *RÉSUMÉS & FICHES*
*Fiches complètes Analyse 1 — L1 Maths*
42 pages, cours + exercices corrigés.
💰 1 500 FCFA
📍 Bibliothèque centrale
👤 Aïcha — wa.me/229XXXXXXXXXX
```

Le bouton **« Partager »** de la page génère exactement ce format.

## 4. Faire grandir le groupe

- Messages dans les groupes de promo et affiches avec QR code (cafétéria, reprographie, cité U).
- Partenariats : reprographes du campus, associations étudiantes, BDE.
- Chaque lundi, publier dans 📢 Annonces le « Top 5 de la semaine ».

## 5. Indicateurs à suivre (tableau simple, chaque semaine)

| Indicateur | Objectif pour passer à l'appli |
|---|---|
| Membres | 500+ |
| Annonces par semaine | 50+ |
| Ventes / services conclus (sondage « VENDU ») | 20+ par semaine |
| Catégorie la plus active | → à mettre en avant dans l'appli |

## 6. Gagner un peu d'argent (plus tard)

- Annonce « à la une » épinglée : 200–500 FCFA.
- Commission ou partenariat avec les reprographes et répétiteurs.
- Publicité des commerces autour du campus.

## 7. Quand passer à la vraie application

Quand les indicateurs ci-dessus sont atteints, ou que les admins n'arrivent plus à modérer.
L'étape suivante pour `campus/index.html` : stocker les annonces en ligne (ex. Firebase ou
Supabase) au lieu du téléphone, ajouter la connexion par numéro, puis l'emballer en APK
avec Capacitor comme Volt Bloc.
